## Context rule

Preserve the underlying identity system rather than copying an existing
execution literally.

When adapting to a new medium, retain the relationships responsible for brand
recognition:

- hierarchy
- personality
- verbal rhythm
- distinctive assets
- visual tension
- photographic principles
- motion character
- interaction character

Do not introduce generic contemporary design conventions when they conflict
with the observed Brand DNA.

Where evidence is uncertain, use the simplest interpretation compatible with
high-confidence brand rules.
