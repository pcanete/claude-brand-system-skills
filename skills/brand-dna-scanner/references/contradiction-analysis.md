# Contradiction Analysis

Brands are often inconsistent.

The scanner must preserve contradictions rather than smoothing them away.

## Detect

- official guideline vs current execution
- current vs legacy logo
- campaign-specific palette
- channel-specific voice
- regional variation
- social vs website mismatch
- old vs new typography
- product-family divergence
- founder vs corporate voice
- stated positioning vs actual selling behavior

## Classification

Possible causes:

- legacy
- campaign
- channel adaptation
- regional adaptation
- rebrand transition
- intentional tension
- accidental inconsistency
- unknown

## Resolution

When possible determine:

CURRENT CORE

LEGACY

EXCEPTION

EMERGING SYSTEM

UNKNOWN

## Output

Contradictions should appear in BRAND_REPORT and BRAND_EVIDENCE.

Do not silently average conflicting evidence into a generic middle.
