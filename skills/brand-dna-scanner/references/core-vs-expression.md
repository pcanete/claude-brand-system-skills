# Core vs Expression

## The hierarchy

BRAND CORE
↓
BRAND SYSTEM
↓
CHANNEL EXPRESSION
↓
CAMPAIGN EXPRESSION
↓
INDIVIDUAL EXECUTION

## Brand Core

Long-lived principles.

Examples:

- positioning
- promise
- personality
- cultural stance
- core visual tension

## Brand System

Repeatable assets/rules.

Examples:

- typography relationships
- core palette
- logo system
- photography principles
- voice principles

## Channel Expression

Medium-specific behavior.

Examples:

- web cursor
- retail signage
- social carousel composition
- packaging hierarchy

## Campaign Expression

Temporary concept layered over the system.

Examples:

- seasonal palette
- launch-specific 3D objects
- event typography variant

## Individual Execution

One artifact.

Never infer global rules from one artifact without supporting recurrence.

## Promotion rule

A behavior may be promoted upward when evidence shows:

- recurrence across multiple independent artifacts
- consistency over time
- appearance across channels
- guideline support
- clear strategic relationship

## Demotion rule

A candidate brand rule should be demoted when:

- it appears in one campaign only
- it is a standard category convention
- it exists because of one platform
- it conflicts with most other current material
- it is legacy
