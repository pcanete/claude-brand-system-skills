# Web Experience DNA

This document extends Brand DNA into digital behavior.

## Important rule

A website can contain highly distinctive behavior that belongs only to that
website.

Do not promote web-specific behavior into global Brand DNA without recurrence
or strategic evidence.

## Analyze

### Narrative

- homepage sequence
- storytelling rhythm
- visual/text balance
- content density
- CTA placement

### Navigation

- desktop
- mobile
- overlays
- mega menus
- state machines
- persistence

### Interaction

- cursor
- hover
- focus
- press
- click
- drag
- swipe
- filtering
- fullscreen
- direct manipulation

### Motion

- loaders
- entrances
- scroll reveals
- scroll-linked scenes
- sticky/pinning
- parallax
- media transitions
- page transitions
- ambient motion

### Media

- image systems
- video
- embeds
- galleries
- interactive scenes
- WebGL/canvas

### Responsive behavior

- scaling
- reflow
- reorder
- replacement
- omission
- interaction substitution
- motion reduction
- recrop

### Runtime behavior

- localization
- timezone
- personalization
- counters
- live data
- availability

### Accessibility

Distinguish declared accessibility from observed behavior.

### Brand relevance

For every major web behavior classify:

- brand-defining
- channel-specific
- campaign-specific
- implementation-specific
- unknown
