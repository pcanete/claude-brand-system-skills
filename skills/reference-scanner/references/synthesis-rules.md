# Synthesis Rules

Checkpoint v0.3.

STYLE_DNA is not a transcript of the reference.

It is a reusable implementation specification.

Prefer relationships:

"Primary project media approaches viewport width and acts as visual punctuation
between dense editorial sections."

Over literal samples:

"width: 1328px"

unless the literal value is itself structurally meaningful.

For every high-salience synthesis:

- preserve evidence refs
- preserve confidence
- preserve salience
- preserve exact/derived/inferred/adaptive/unknown mode

Do not turn technology hypotheses into design rules.

Generate explicit:

- must_preserve
- may_adapt
- must_not_introduce
