# Visual Analysis

Checkpoint v0.3.

Analyze visual identity through relationships rather than style adjectives.

Inspect:

- hierarchy
- visual mass
- density
- negative space
- composition
- symmetry/asymmetry
- contrast
- color roles
- surface treatment
- typography-image relationship
- editorial rhythm
- repetition
- intentional irregularity

A good description explains WHY the site feels distinctive.

Avoid generic labels such as "modern", "premium", or "minimal" without
describing the observed mechanisms producing that impression.
