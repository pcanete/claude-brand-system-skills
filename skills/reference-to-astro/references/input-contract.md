# Input Contract

## STYLE_DNA.json

Authoritative for:

- visual language
- typography behavior
- layout relationships
- composition
- spacing rhythm
- media treatment
- interaction grammar
- motion language
- responsive transformations

## REFERENCE_EVIDENCE.json

Authoritative for provenance.

Use it to distinguish:

- directly observed behavior
- derived rules
- inferred behavior
- technology hypotheses
- unknowns

## CONTENT_MANIFEST.json

Authoritative for:

- copy
- images
- video
- logos
- icons
- links
- metadata
- content structure

## BUILD_BRIEF.md

Authoritative for:

- site purpose
- route requirements
- business requirements
- integrations
- deployment requirements
- explicit user overrides

## Conflict rule

Do not replace reference-derived visual rules with generic frontend design
preferences.

Do not replace supplied content with reference content.

Reference defines language.

Manifest defines content.

Brief defines purpose and functional requirements.
