# Manual composition

The manual is an inspection surface, not a decorative brand book.

## Order

Prefer this sequence when evidence supports it:

1. cover and brand essence;
2. recognition model and distinctive assets;
3. verbal identity;
4. visual identity;
5. photography, motion and experience;
6. operational rules;
7. coverage, evidence and limitations;
8. approval checklist.

The first screen should make the identity recognizable. Later screens should
make the reasoning auditable.

## Composition rules

- Use one dominant statement per section.
- Keep evidence near the claim it supports.
- Show arrays as systems, not undifferentiated paragraphs.
- Use the brand palette only when it is recorded; otherwise use a neutral shell.
- Load local fonts only when the user owns or supplies them.
- Never hide low coverage or limitations in an appendix.
- Keep review controls visually distinct from brand expression.

## Source mapping

Every section declares `source_paths`, using dotted paths into `BRAND_DNA`.
Every claim that needs provenance declares `evidence_refs`. This mapping makes
the manual regenerable and prevents visual polish from laundering an inference
into an established rule.
